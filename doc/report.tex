\section{Introduction}

Labelme is a widely used, open-source graphical image annotation tool that
enables users to label objects in images for computer vision tasks. Developed
in Python and using the Qt library for its graphical interface, it is
cross-platform and supports a variety of annotation types, including polygons,
rectangles, circles, lines, and points. This versatility makes it suitable for
diverse tasks such as object detection, semantic segmentation, and instance
segmentation.

For every annotated image, Labelme generates a corresponding JSON file. This
file contains metadata about the image (such as its path and dimensions) and a
detailed list of shapes representing the annotations, including their label
names and coordinate points. The output of a dataset annotated with Labelme is
typically structured as shown in Fig. \ref{fig:labelme_structure}.

\begin{figure}[htbp]
\dirtree{%
	.1 labelme\_dataset/.
	.2 img1.json.
	.2 img1.jpg.
	.2 img2.json.
	.2 img2.png.
	.2 subdirectory/.
	.3 img3.json.
	.3 img3.jpg.
	.2 \ldots.
}
\caption{Structure of a Labelme dataset}
\label{fig:labelme_structure}
\end{figure}

While this structure is rich in information and easy to parse programmatically,
it is not directly compatible with the input requirements of popular deep
learning frameworks and model architectures. Frameworks like Darknet/YOLO,
standard COCO-based models, or Pascal VOC-based pipelines require annotations
in specific formats---such as aggregated JSONs, flat text files with normalized
coordinates, or XML files---often accompanied by strict directory structures.

The goal of the Labelme converter is to bridge this gap. It serves as a
comprehensive tool that parses the raw Labelme dataset and transforms it into a
format ready for the training process of a neural network, thereby streamlining
the workflow from data annotation to model training.

\section{Converter}

The Labelme converter is a Python script that takes the Labelme
dataset as input and generates a new dataset in a different format. As of
writing this report, the converter is capable of converting the dataset into
the following formats:

\begin{itemize}
	\item COCO
	\item YOLO
	\item Pascal VOC
\end{itemize}

\subsection{labelme2coco module}

The labelme2coco module takes the directory of the Labelme
dataset as input and generates a directory with the COCO dataset. The
module supports splitting the dataset into training and validation sets. The
split is done randomly, and the user can specify the ratio of the split. The
output directory will contain the structure shown in Fig. \ref{fig:coco_structure}.

\begin{figure}[htbp]
\dirtree{%
	.1 coco\_dataset/.
	.2 annotations/.
	.3 instances\_train.json.
	.3 instances\_val.json.
	.3 class1\_train.json.
	.3 class1\_val.json.
	.3 \ldots.
	.2 train/.
	.3 000000000001.jpg.
	.3 000000000002.jpg.
	.3 \ldots.
	.2 val/.
	.3 000000000501.jpg.
	.3 000000000502.jpg.
	.3 \ldots.
}
\caption{Structure of the generated COCO dataset}
\label{fig:coco_structure}
\end{figure}

The JSON files in the annotations directory have some required
fields which should derive from the Labelme dataset. The minimum required
fields for the COCO format are shown in Listing \ref{lst:coco_json}.

\begin{lstlisting}[style=json, caption={Example COCO format JSON file}, label={lst:coco_json}]
{
	"images": [
		{
			"id": 1,
			"width": 800,
			"height": 600
			"file_name": "000000000001.jpg",
		},
		...
	],
	"annotations": [
		{
			"id": 1,
			"image_id": 1,
			"category_id": 1,
			"segmentation": [[x1, y1, x2, y2, ...]],
			"area": 123.45,
			"bbox": [x, y, width, height]
			"iscrowd": 0,
		},
		...
	],
	"categories": [
		{
			"supercategory": "superclass1"
			"id": 1,
			"name": "class1"
		}
	]
}
\end{lstlisting}

Almost all fields can be derived from the Labelme dataset. The
fields "supercategory", and "iscrowd" can be set to default values. The
"area" and "bbox" fields can be calculated from the segmentation
coordinates based on the shape type.

\subsection{labelme2yolo module}

The labelme2yolo module takes the directory of the Labelme
dataset as input and generates a directory with the YOLO dataset. The
module supports splitting the dataset into training and validation sets. The
split is done randomly, and the user can specify the ratio of the split. The
output directory will contain the structure shown in Fig. \ref{fig:yolo_structure}.

\begin{figure}[htbp]
\dirtree{%
	.1 yolov8\_dataset/.
	.2 data.yaml.
	.2 images/.
	.3 train/.
	.4 img001.jpg.
	.4 \ldots.
	.3 val/.
	.4 img101.jpg.
	.4 \ldots.
	.2 labels/.
	.3 train/.
	.4 img001.txt.
	.4 \ldots.
	.3 val/.
	.4 img101.txt.
	.4 \ldots.
}
\caption{Structure of the generated YOLO dataset}
\label{fig:yolo_structure}
\end{figure}

The data.yaml file contains the fields shown in Listing \ref{lst:yolo_yaml}.

\begin{lstlisting}[style=json, caption={Example YOLO format data.yaml file}, label={lst:yolo_yaml}]
path: absolute/path/to/yolov8_dataset
train: images/train
val: images/val
test:

names:
	0: class1
	1: class2
	2: class3
	...
\end{lstlisting}

The text files contains the annotations for each image. The format
of the text files is shown in Listing \ref{lst:yolo_txt}.

\begin{lstlisting}[style=json, caption={Example YOLO format text file}, label={lst:yolo_txt}]
	class_id1 x_center y_center width height
	class_id2 x_center y_center width height
	...
\end{lstlisting}

These values should ne calculated based on the shape type and the
coordinates of the shape.

\subsection{labelme2voc module}

The labelme2voc module takes the directory of the Labelme
dataset as input and generates a directory with the Pascal VOC dataset. The
module supports splitting the dataset into training and validation sets. The
split is done randomly, and the user can specify the ratio of the split. The
output directory will contain the structure shown in Fig. \ref{fig:voc_structure}.

\begin{figure}[htbp]

\caption{Structure of the generated Pascal VOC dataset}

The text files contains the names of the images files. The
format of the text files is shown in Listing \ref{lst:voc_txt}.

\begin{lstlisting}[style=json, caption={Example Pascal VOC format text file}, label={lst:voc_txt}]
000001.jpg
000002.jpg
...
\end{lstlisting}

The XML files contains the annotations for each image. The main challenge in
transforming the Labelme dataset to the Pascal VOC format is to convert the
segmentation coordinates to the bounding box coordinates for polygon and
circle shapes, and to achieve this, we can take the minimum and maximum
coordinates of the shape.
